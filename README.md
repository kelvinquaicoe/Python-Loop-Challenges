# Python Loop Challenges

A small collection of three Python exercises focused on loops, conditions, and numeric input.

## Challenges

1. **Collatz sequence** — repeatedly halves even numbers and applies `3n + 1` to odd numbers until reaching 1.
2. **Prime checker** — determines whether an integer is prime, including correct handling of values below 2.
3. **Multiplication table** — prints a neatly aligned 10 × 10 table.

## Requirements

- Python 3.8 or newer
- No third-party packages

## Run

```bash
python loop_challenges.py
```

## Concepts practiced

While and for loops, modulo arithmetic, functions, input validation, and formatted output.

## Development note

These exercises began as COMP 163 coursework and have been cleaned up as a learning project. The Collatz sequence is generated only for positive starting integers.
